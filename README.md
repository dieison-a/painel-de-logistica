# Demonstração de operações logísticas

Painel demonstrativo de operações para uma loja fictícia. A interface reúne pedidos, estados de integração e acompanhamento em um único fluxo.

## Área e semestres relacionados

Área: desenvolvimento e integrações. Conteúdos relacionados: Lógica de Programação, Programação Orientada a Objetos, Banco de Dados e Programação para Web I e II. Os materiais disponíveis não identificam os semestres específicos dessas disciplinas.

## Resumo acessível

A tela contém indicadores, busca, filtros e uma tabela de pedidos com situação e previsão. A tabela pode ser percorrida horizontalmente em telas estreitas; rótulos e estados são apresentados como texto.

## Executar localmente

Abra `index.html` em um navegador atualizado. Não é necessário servidor, instalação ou conexão com a internet.

## Limitações e transparência

Todos os pedidos e indicadores são simulados e permanecem no código local; não há integração com APIs ou rede externa. Projeto elaborado com assistência de inteligência artificial e revisão humana. Não descreve experiência real, resultados empresariais ou código sem assistência de IA.
