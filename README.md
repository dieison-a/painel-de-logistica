# SaaS Logistics Demo

Painel demonstrativo de operações logísticas para uma loja fictícia. A interface reúne pedidos, estados de integração e ações de acompanhamento em um único fluxo.

## Funcionalidades

- Busca por pedido ou destino.
- Filtros por situação operacional.
- Detalhes de cada pedido com dados simulados.
- Interface responsiva sem bibliotecas externas.

## Conteúdos relacionados

Lógica de Programação, Programação Orientada a Objetos, Banco de Dados e Programação para Web I e II.

## Executar

Abra `index.html` em um navegador. Todos os dados são estáticos e fictícios; nenhuma API ou rede externa é acessada.
